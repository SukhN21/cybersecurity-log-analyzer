# Cybersecurity Log Analyzer

## Project Description
This project is a simple cybersecurity tool that helps identify failed login attempts.

## Features
- Analyze security logs
- Count failed login attempts
- Display security alerts

## Technologies
- Python
- GitHub
- Freshworks

## Project Branches
- main: Final working code
- development: Testing and development
- feature/log-analysis: Log analysis feature

## How to Run
Download the Python file and run it using Python 3.
